Funzionamento Enigma:
- Inserisci una lettera/frase da criptare
- ogni lettera passa in enigma e cambia tramite:
	- plugboard										mappa.keySet().get(i) oppure (char key : mappa.keySet())
	- rotore 1
	- rotore 2
	- rotore 3
	- reflector
	- rotore 3
	- rotore 2
	- rotore 1
	- plugboard
- Frase criptata (output)

Rotori:
- {<'A', 'B'>, <'C', 'D'>, ...}
- {<'A', 'B'>, <'C', 'D'>, ...}
- {<'A', 'B'>, <'C', 'D'>, ...}
 

Configurazione impostazioni:
- connessioni nella plugboard (una decina di cavi → 20 lettere connesse → 10 Pairs)
	- nella plugboard non è detto che tutte le lettere siano connesse
- ordine dei rotori (5 rotori → sceglierne 3, metterli in un determinato ordine)
- ordine delle tacche laterali dei rotori (a che numero ogni rotore fa girare il successivo) 			<-- IMPORTANTE
- ordine dei numeretti sui rotori (posizione iniziale)

import com.google.gson.Gson;
import com.google.gson.reflect.TypeToken;

import java.lang.reflect.Type;
import java.util.HashMap;
import java.util.Map;

public class JsonToHashMapExample {
    public static void main(String[] args) {
        String json = "{\"nome\":\"Luca\", \"eta\":30, \"isStudente\":false}";

        Gson gson = new Gson();

        // Tipo generico per HashMap<String, Object>
        Type type = new TypeToken<HashMap<String, Object>>() {}.getType();

        // Conversione
        HashMap<String, Object> map = gson.fromJson(json, type);

        // Stampa
        for (Map.Entry<String, Object> entry : map.entrySet()) {
            System.out.println(entry.getKey() + " => " + entry.getValue());
        }

        // Accesso ai dati
        String nome = (String) map.get("nome");
        Double eta = (Double) map.get("eta"); // numeri diventano Double per default
        Boolean isStudente = (Boolean) map.get("isStudente");

        System.out.println("Nome: " + nome);
        System.out.println("Età: " + eta.intValue());
        System.out.println("Studente: " + isStudente);
    }
}

Il file Main.java è il punto d’ingresso della tua applicazione Enigma. Serve a:

Caricare o inizializzare la configurazione della macchina

Creare un'istanza della macchina Enigma

Avviare l’interfaccia utente (es. console)

Gestire l’eventuale salvataggio delle impostazioni alla fine

✅ Struttura consigliata per Main.java
package it.giumbociccio.enigma;

import it.giumbociccio.enigma.model.EnigmaSettings;
import it.giumbociccio.enigma.logic.EnigmaMachine;
import it.giumbociccio.enigma.console.EnigmaConsoleUI;
import it.giumbociccio.enigma.config.SettingsManager;

public class Main {
    public static void main(String[] args) {
        try {
            // 1. Carica le impostazioni da file JSON
            SettingsManager settingsManager = new SettingsManager("config/currentSettings.json");
            EnigmaSettings settings = settingsManager.loadSettings();

            // 2. Crea la macchina Enigma con le impostazioni caricate
            EnigmaMachine machine = new EnigmaMachine(settings);

            // 3. Avvia l’interfaccia console
            EnigmaConsoleUI consoleUI = new EnigmaConsoleUI(machine);
            consoleUI.start();

            // 4. Salva le impostazioni aggiornate al termine (opzionale)
            settingsManager.saveSettings(machine.getCurrentSettings());

        } catch (Exception e) {
            System.err.println("Errore durante l'avvio della macchina Enigma:");
            e.printStackTrace();
        }
    }
}
🔍 Cosa serve avere perché questo funzioni?
SettingsManager (nel package config)
Classe che si occupa di leggere e scrivere il file JSON di configurazione.

Internamente usa una libreria tipo Jackson o Gson.

EnigmaSettings (nel package model)
Contiene la configurazione della macchina: ordine rotori, plugboard, offset, ecc.

EnigmaMachine (nel package logic)
Incapsula la logica della cifratura.

EnigmaConsoleUI (nel package console)
Gestisce l’interazione da terminale con l’utente (inserimento lettere, comandi, stampa output).
